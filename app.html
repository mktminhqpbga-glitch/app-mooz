Kết nối AI

Dùng tab AI đã đăng nhập không cần API key. Mỗi node có bộ chọn AI riêng. Màu xanh: ô chat sẵn sàng; đỏ: kiểm tra thất bại; xám: chưa có tab/khóa.

Mở cuộc trò chuyện muốn dùng trong một tab, rồi chọn đúng tab. Workflow không tự chuyển sang cuộc trò chuyện khác.

API key chỉ giữ trong phiên trình duyệt, không đưa vào workflow xuất ra. Đóng trình duyệt cần nhập lại. Yêu cầu API có thể phát sinh phí.

Tạo ảnh hàng loạt

Không cần kịch bản. Mỗi dòng là một prompt; nếu prompt có nhiều dòng, cách các prompt bằng một dòng trống. Tối đa 50 ảnh mỗi đợt.

Các ảnh chạy lần lượt. Đóng cửa sổ này không xóa danh sách prompt. API có thể tính phí theo từng ảnh.

Build nodes from a scene script

Paste a scene script using the Grumbo & Snowy form. MuseFlow reads each scene’s opening/ending frames, timed actions, image/video prompts, audio, shared locks and negative prompt, then connects the scene nodes and orders videos on the Timeline.

Download the strict template to fill in yourself or give to an AI. Keep the headings and field order unchanged.
